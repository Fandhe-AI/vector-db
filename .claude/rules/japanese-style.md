# 日本語出力スタイル

## 基本

- ユーザーとのやりとり・報告・計画・コミットメッセージ本文・ドキュメントはすべて日本語で行う
- 技術用語・コード識別子・コマンドは原語（英語）のまま使う（例: workspace, trait, `cargo test`）

## 表記

- 全角と半角の間に不要なスペースを入れる/入れないは既存文書（README.md・AGENTS.md）の流儀に合わせる（本リポは「日本語 英単語 日本語」の半角スペース区切りを採用）
- 箇条書き・表を活用し、冗長な前置きを避ける
- 見出しは名詞止めまたは体言止めを基本とする

## コード内

- コード内コメント・ドキュメンテーションコメントも日本語で書く（[code-comment-style](./code-comment-style.md)）
- エラーメッセージ・ログなどプログラムの出力文字列は英語とする（wire プロトコル互換性・運用ツール連携のため）

## コミット・PR

- コミットメッセージ: type/scope は Conventional Commits の英語規約、説明文は日本語（例: `feat(engine): 検索カーネルの C1 クエリを実装`）
- PR タイトル・本文も同様の形式とする
