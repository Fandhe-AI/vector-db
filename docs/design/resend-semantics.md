# ADR: 同一パスファイル再送セマンティクス

- ステータス: Proposed（本 PR のマージ後、別コミットで Accepted に更新する）
- 対応: TASK-123（MS-1 / phase:1・基盤・工程管理）
- 反映先（実装・テスト）: TASK-120（INDEX-1/2）・TASK-93（RECOVER-2）
- 関連: TASK-92・TASK-80

## 背景

取り込み時に同一（テナント, テーブル, パス）のファイルが再送された場合の
レコード処理方針を本実装がどう定めるかを規定する。TASK-120・TASK-93 の実装は
この決定に従う。検討する論点自体も private spec 側の内部設計判断に含まれるため
本ドキュメントには記載しない。

## 決定事項

同一（テナント, テーブル, パス）のファイル再送時のレコード処理方式、冪等性判定
（TASK-92・TASK-80）との適用順序、失敗時の挙動、パス比較・正規化の扱い、および
検討した代替案の比較は、private spec（`docs/spec`）側の内部設計判断に該当するため
本ドキュメントには記載しない。決定の詳細は spec リポジトリの該当タスクを参照する。

本リポジトリで公開している設計方針の範囲は README.md「実装方針（要点）」を参照する。

## 影響

- TASK-120（INDEX-1/2）: 取り込み処理で本決定に基づく実装を行う
- TASK-93（RECOVER-2）: リカバリ処理で本決定と整合する状態復元を行う
- 上記 2 タスク側で本決定に対応するテストを追加する（本タスクは基盤・工程管理タスク
  であり、対応ビヘイビア ID なしのため本 PR ではテスト追加を行わない）

## スコープ外

- 決定事項に基づく実装・テスト追加（TASK-120・TASK-93 側で対応）
- コンテンツハッシュによる no-op 最適化（将来課題。spec 側の代替案検討を参照）
- `docs/spec` 側への本決定の反映は spec リポジトリ側の作業であり、本リポジトリから
  は submodule を変更しない
